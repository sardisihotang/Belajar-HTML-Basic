## 📌 Tentang Proyek / About the Project

**[ID]** Repositori ini adalah dokumentasi perjalanan belajar fundamental web development, khususnya HTML5. Terdiri dari lebih dari 20 modul latihan komprehensif, mulai dari tag dasar pembentuk teks, penyematan multimedia, pembuatan form dan tabel, hingga implementasi fitur HTML5 tingkat lanjut seperti SVG, Canvas, Form Validation, dan Web Storage.

**[EN]** *This repository documents the learning journey of fundamental web development, specifically HTML5. It consists of over 20 comprehensive exercise modules, ranging from basic text-formatting tags, multimedia embedding, form and table creation, to the implementation of advanced HTML5 features such as SVG, Canvas, Form Validation, and Web Storage.*

---

## 📂 Struktur Pembelajaran / Learning Structure

Materi di dalam repositori ini disusun secara berurutan berdasarkan tingkat kompleksitas:

* **Basic HTML Tags:** Pemahaman `Heading`, `Paragraph`, `Line breaks`, `Horizontal rules`, dan `Extra Tags`.
* **Hyperlinks & Lists:** Penggunaan tautan antar halaman web (`<a>`) dan pembuatan daftar terurut/tidak terurut.
* **Tables & Forms:** Pembuatan struktur tabel dan elemen input formulir interaktif.
* **Multimedia:** Penyematan Gambar (`<img>`), Audio, dan Video ke dalam halaman web.
* **CSS Integration:** Pengenalan dasar integrasi CSS dengan HTML (Cascade, Inheritance, Colors, Box Model, Padding, dan Display Model).
* **Mini Projects:** Implementasi pembuatan struktur artikel dan perpustakaan sederhana.
* **Advanced HTML5:** 
  * `SVG`: Pembuatan grafis vektor skalabel.
  * `CANVAS`: Menggambar grafis dinamis menggunakan integrasi JavaScript.
  * `Web Storage`: Penyimpanan data lokal pada browser (Local Storage/Session Storage).
